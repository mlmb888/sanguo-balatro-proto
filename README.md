## 计分（取最高档 + 声明加成）

| 结构 | 条件 | 底分档 | 倍率 |
|------|------|--------|------|
| 散兵 | 未成结构 | Σ点数 | ×1 |
| 同阵 | ≥3 同阵营 | 25+Σ | ×2（5 张齐射 ×3） |
| 组将 | 凑齐武将全名 | 50+Σ | ×3；兼同阵再 +1 |
| 连名 | 一次组出 2 将 | 同组将 | 倍率再 ×2 |

宣战花色每张 +4；阵营共鸣上限 +3；虎牢关散兵 0 分。
