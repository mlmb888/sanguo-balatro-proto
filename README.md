## 已实现（v0.1 试玩）

- 52 牌库：魏/蜀/吴/群 × 点数角标 + 中央汉字字位
- 牌型表（含组将）；取最高牌型
- 手牌 8、出牌≤5、出牌 4 / 弃牌 3 / 气势 3
- 武将小丑：关羽、张飞、赵云、诸葛亮（观星）
- 章一：黄巾小关1/2 + Boss 虎牢关（对子及以上才计分）
- 关间商店：招募武将 / 剔除羸兵 / 劫掠补给
- 组将解锁并自动装入空槽
- 水墨风 CSS 竖屏 UI，结算飘字

## 未实现 / 简化

- 刘备、曹操、周瑜、吕布仅占字位与组将识别，无小丑效果
- 观星：顶 3 张，保持顺序或洗乱放回（无任意重排拖拽）
- 小丑槽满时无手动替换 UI（商店可扩槽至 4）
- 无音效、无存档、无微信 SDK / 分享
- 数值未精细平衡（赵云+短牌极易破关，便于通关演示）

## 与大纲差异

- 开局仅关羽；商店可招募张飞/诸葛亮/赵云
- 牌面点数筹码并入底分（类似 Balatro chips），目标分 80/180/280；开局仅关羽；弃牌 2；赵云已削弱
- 商店「剔除羸兵」用提高牌库点数分布实现，非物理删牌

## 不做清单

格子塔防、保护阿斗、同字合成升级、血条对砍替代计分。
